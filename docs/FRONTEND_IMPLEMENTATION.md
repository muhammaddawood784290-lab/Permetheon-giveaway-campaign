# Frontend Implementation

Status: Ready for implementation

## Public page

The giveaway page includes the hero, prize, eligibility, process, form, FAQ, rules summary, privacy summary, contact section, and footer.

## Visual direction

- Black, white, charcoal, and gray only.
- Responsive from mobile through desktop.
- Accessible labels, focus states, error messages, and keyboard navigation.
- No invented testimonials, statistics, awards, or logos.

## Form behavior

- Validate on submit.
- Focus the first invalid field.
- Require rules and privacy consent.
- Keep marketing consent optional.
- Show a success state after a saved entry.
- Do not expose database errors or secrets to visitors.

## Admin UI

Use ADMIN_PANEL_SPEC.md. Keep admin screens visually consistent with the public campaign page while making dense data easy to scan.
